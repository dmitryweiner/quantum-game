# Quantum Game — план разработки

Веб-игра про «странности» квантового мира. Игрок — наблюдатель внутри
двумерного мира, и сам факт его взгляда меняет происходящее. Цель игры:
через игровые механики дать интуицию о суперпозиции, коллапсе, запутанности,
неопределённости, туннелировании и интерференции, не прибегая к формулам.

Статус документа: **черновик v0.1** — часть решений принята по умолчанию и
помечена ⏳ как ожидающая подтверждения (см. раздел «Открытые вопросы»).

---

## 1. Концепция

### 1.1. Главная механика — «взгляд наблюдателя»

- Игрок управляет персонажем-наблюдателем 👁️ (WASD / стрелки / тач-джойстик).
- У наблюдателя есть **поле зрения** — конус, направленный на курсор мыши
  (или на вторую тач-точку). Всё внутри конуса считается **измеряемым**.
- Квантовые объекты (частицы, кот, ключи, двери…) существуют в двух режимах:
  - **вне взгляда** — в суперпозиции: рисуются полупрозрачными «призраками»
    во всех возможных позициях/состояниях, со временем «расплываются»;
  - **во взгляде** — коллапсируют в одно состояние по правилу Борна
    (случайный выбор с вероятностью |амплитуда|²) и ведут себя классически.
- Отвёл взгляд — объект снова начинает «расплываться» из того места, где
  его видели в последний раз.

Таким образом игрок не «толкает» предметы, а управляет тем, **когда и на что
смотреть**, чтобы вероятности сложились в его пользу.

### 1.2. Формат

- Головоломка из коротких уровней (10–20 секунд на попытку, много попыток).
- Каждый уровень демонстрирует один эффект; уровни сгруппированы в «главы».
- У каждого уровня есть цель («довести кота до двери», «зажечь обе лампы»,
  «не дать ядру распасться 30 секунд») и короткое пояснение после прохождения:
  «что сейчас произошло с точки зрения физики» (1–3 предложения, без формул).
- Отдельный режим **«песочница»** — просто побродить среди квантовых объектов.

### 1.3. Графика

- 2D, вид сверху. Все спрайты — эмодзи, отрисованные как текст
  (🐱 🧱 🔑 🚪 💡 ☢️ 🔴 🔵 ⚛️ 👁️ 🕶️ и т. п.).
- Суперпозиция визуализируется прозрачностью (альфа ∝ вероятности) и
  лёгким дрожанием; коллапс — короткая вспышка + звук.
- Запутанность — пунктирная «нить» между партнёрами.

## 2. Какие эффекты показываем

Таблица — что показать, через какую механику, и какой пазл из этого сделать.
Приоритет: **P0** — обязательно для первого релиза, **P1** — следующий релиз,
**P2** — если останутся силы.

| # | Эффект | Игровая механика | Пример уровня | Приоритет |
|---|--------|------------------|---------------|-----------|
| 1 | **Суперпозиция и коллапс (эффект наблюдателя)** | Объект вне взгляда «размазан» по нескольким клеткам; взгляд фиксирует одну по правилу Борна | Кот 🐱 в суперпозиции «слева/справа от стены». Нужно посмотреть на него в момент, когда вероятность быть у двери максимальна | P0 |
| 2 | **Нелокальность / запутанность** | Пара частиц 🔴🔵 с общим состоянием. Измерение одной мгновенно фиксирует другую, как бы далеко она ни была | Два ключа 🔑 в разных концах карты: нужно, чтобы оба оказались «красными». Смотришь на ближний — дальний определяется сам | P0 |
| 3 | **Неопределённость (Гейзенберг)** | Чем у́же конус зрения (точнее «меряем» координату), тем сильнее разброс скорости после коллапса: объект «выстреливает» в случайную сторону | Нужно провести частицу через узкий проход: узкий взгляд даёт точную позицию, но непредсказуемую скорость; широкий — наоборот | P0 |
| 4 | **Туннелирование** | У частицы есть вероятность оказаться по ту сторону стены 🧱, зависящая от толщины стены и «энергии» частицы | Запереть/пройти сквозь стену, не имея двери. Пока не смотришь — частица «просачивается» | P1 |
| 5 | **Квантовый эффект Зенона** | Частое наблюдение «замораживает» эволюцию | Ядро ☢️ распадается за ~5 секунд без присмотра. Нужно продержать его 30 секунд, не отводя взгляд (а в это время что-то ещё требует внимания) | P1 |
| 6 | **Интерференция (двухщелевой опыт)** | Поток частиц через две щели. Экран показывает интерференционные полосы, пока игрок **не смотрит на щели**; взгляд на щели убивает интерференцию → две полосы | Нужно зажечь лампу 💡, стоящую в «тёмной» полосе интерференции: единственный способ — посмотреть на щели | P1 |
| 7 | **Базисы измерения (упрощённый Белл)** | Очки 🕶️ наблюдателя можно «повернуть» (базис Z/X). Запутанные частицы коррелируют только в одинаковом базисе | Пазл на подбор базиса, чтобы два датчика сработали одновременно | P2 |
| 8 | **Квантовый ластик** | Информацию «через какую щель» можно стереть, и интерференция вернётся | Расширение уровня 6 | P2 |
| 9 | **Квантовая телепортация / no-cloning** | Нельзя скопировать неизвестное состояние, но можно «переслать» через запутанную пару | Финальный уровень главы | P2 |

## 3. Технологический стек

| Слой | Выбор | Почему |
|------|-------|--------|
| Язык | **TypeScript** (strict) | требование |
| Движок | **Phaser 3** ⏳ | сцены, input, твины, тач из коробки; эмодзи рисуются через `Text`; большое комьюнити. Альтернатива — PixiJS (легче, но всё «игровое» писать самим) |
| Сборка | **Vite** | быстрый dev-сервер, простая сборка статики для GitHub Pages |
| Пакетный менеджер | **npm** ⏳ (lock-файл в репо) | нет лишних зависимостей в CI |
| Тесты | **Vitest** | юнит-тесты квантового ядра (чистый TS без рендера) |
| Линт/формат | **ESLint + Prettier** ⏳ (или Biome одним пакетом) | |
| Звук | Phaser Audio, короткие синтезированные/CC0 сэмплы | |
| Деплой | **GitHub Pages** через GitHub Actions | требование «сборка через GH Actions» |

Ключевой принцип: **квантовая модель не зависит от движка**. Папка
`src/quantum/` — чистый TypeScript с детерминированным ГСЧ (seed), полностью
покрытый тестами. Phaser только рисует и передаёт события.

### 4.1. Модель квантового объекта (упрощённая, но честная)

Полное решение уравнения Шрёдингера не нужно. Используем дискретную модель:

- `Superposition<S>` — массив ветвей `{ state: S, amp: Complex }`, нормированный.
  - `evolve(dt)` — «расплывание»: амплитуда перетекает в соседние клетки
    (дискретный random walk / простая диффузия амплитуды с фазой).
  - `measure(rng)` — выбор ветви с вероятностью `|amp|²`, схлопывание в неё.
- `EntangledPair` — вектор состояния 2 кубитов (4 комплексных амплитуды).
  - Измерение одного кубита в базисе Z или X ⇒ частичный коллапс, второй
    кубит получает условное состояние. Корреляции Белла получаются «бесплатно».
- Неопределённость: ширина конуса зрения `σx` ⇒ после коллапса импульс
  сэмплируется из нормального распределения с `σp = ħ_game / (2·σx)`.
- Туннелирование: `P = exp(-2·κ·d)`, где `d` — толщина стены, `κ` зависит от
  «энергии» частицы. Проверяется при каждом столкновении со стеной вне взгляда.
- Зенон: состояние «не распалось» эволюционирует как `cos²(ωt)`; наблюдение
  сбрасывает `t` в ноль с вероятностью выжить `cos²(ω·Δt)`.
- Интерференция: яркость на экране считается аналитически
  (`cos²(π·d·sinθ/λ)` × огибающая щели); флаг «щели наблюдаются» переключает
  на сумму двух одиночных распределений.

Все функции чистые, принимают `rng`, поэтому воспроизводимы в тестах.

### 4.2. Цикл кадра

1. `GazeSystem` вычисляет, какие объекты попали в конус наблюдателя.
2. Для объектов **в конусе**: если были в суперпозиции — `measure()`,
   событие `collapsed` (вспышка, звук), дальше — классическая физика.
3. Для объектов **вне конуса**: `evolve(dt)` — ветвление/расплывание,
   проверка туннелирования у стен, тик распада.
4. Запутанные партнёры синхронизируются через общий `EntangledPair`.
5. `GhostRenderer` рисует ветви (альфа = вероятность), `HUD` — цель уровня.
6. Проверка условия победы/поражения уровня.

## 6. CI/CD (GitHub Actions)

- **`ci.yml`** — на `push` и `pull_request`:
  `npm ci` → `npm run lint` → `npm run typecheck` → `npm test` → `npm run build`.
- **`deploy.yml`** — на `push` в `main`:
  сборка Vite с `base: '/quantum-game/'` → `actions/upload-pages-artifact` →
  `actions/deploy-pages`. Адрес: `https://dmitryweiner.github.io/quantum-game/` ⏳
- Защита `main`: PR обязателен, CI должен быть зелёным (настраивается в
  настройках репозитория).
